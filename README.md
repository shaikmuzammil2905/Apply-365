# Apply365 — Services for People

**Apply365** is a modern, responsive, multi-page web portal built for Indian civic identity and commercial documentation assistance. Combining the sleek aesthetics of a modern digital SaaS with the clear, reassuring clarity of a trusted government facilitation desk.

**Brand Tagline:** Services for People  
**Main Headline:** Your Documents. Our Priority.  
**Supporting Headline:** Government & Business Services Made Easy.

---

## 🌟 Key Features

1. **Seven Dedicated Service Modules:**
   - **Aadhaar Card** (`/services/aadhaar`): Address updates and new enrolment assistance adhering to UIDAI guidelines.
   - **PAN Card** (`/services/pan-card`): New PAN cards and correction requests via NSDL / UTIITSL.
   - **Voter ID** (`/services/voter-id`): Form 6 new voter registration, constituency shifting, and digital e-EPIC download.
   - **MSME / Udyam Registration** (`/services/msme`): Micro, Small, and Medium enterprise government certification for loans and subsidies.
   - **Labour License** (`/services/labour-license`): Andhra Pradesh & Telangana Shops and Establishments Act commercial compliance with Telugu name-board guidelines.
   - **UAN / PF Services** (`/services/uan-pf`): EPFO Universal Account Number generation, KYC seeding, and online claims.
   - **ESI Details Update** (`/services/esi`): Insured person updates, family member dependant additions, and dispensary change guidance.

2. **Interactive Documents Required Checklist (`/documents-required`):**
   - Service-by-service accordion checklists with exact document criteria.
   - Interactive checkboxes with real-time percentage completion calculation.
   - Filter and search functionality.
   - **Print Checklist** button optimized with clean print stylesheets.
   - **Download Checklist** button generating a clean offline `.txt` reference guide.

3. **5-Step Application Workflow (`/apply`):**
   - Step 1: Select Service
   - Step 2: Contact Information with 10-digit Indian mobile validation
   - Step 3: Service-specific document readiness check
   - Step 4: Specific request details & urgency settings
   - Step 5: Review & Submit with privacy consent and direct WhatsApp enquiry fallback

4. **Branding & Visuals:**
   - Official Apply365 logo with transparent asset handling.
   - Responsive hero section utilizing desktop and mobile hero graphics with bright vibrant styling.
   - Dedicated About Us, Contact Us, Privacy Policy, and Terms & Conditions pages.
   - Sticky navigation header with services dropdown and mobile drawer menu.
   - Floating WhatsApp support button and Back to Top widget.

## 🛠️ Tech Stack

- **Framework:** React 18 + TypeScript + Vite
- **Routing:** React Router DOM (client-side routing)
- **Styling:** Tailwind CSS + PostCSS + Autoprefixer
- **Icons:** Lucide React
- **Animations & Interactivity:** Canvas Confetti, Tailwind transitions

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation & Development

```bash
# Install dependencies
npm install

# Run the local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
